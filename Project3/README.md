# Project 3: Heat Equation Benchmarks

This project benchmarks an implicit 2D heat equation solver using serial, MPI, hybrid MPI/OpenMP, and OpenMP GPU-offload implementations. The MPI solver uses row decomposition; the scaling experiments use nonblocking halo exchange.

## Running experiments on Vanda

From the project directory on Vanda, submit the PBS script for the experiment with `qsub`:

| Experiment | Submit | Runner / implementation | Results folder |
|---|---|---|---|
| CPU decomposition and communication sweep | `qsub vanda_jobs_cpu.pbs` | `sweep_experiments.sh`; MPI variants and serial references | `results/cpu_sweep_intermediate_ranks/` |
| Strong scaling | `qsub vanda_jobs_strong_scaling.pbs` | `run_strong_scaling.sh`, `heat_mpi_nonblocking_implicit.cpp` | `results/strong_scaling/` |
| Weak scaling | `qsub vanda_jobs_weak_scaling.pbs` | `run_weak_scaling.sh`, `heat_mpi_nonblocking_implicit.cpp` | `results/weak_scaling/` |
| Serial grid-size sweep | `qsub vanda_jobs_serial_size_sweep.pbs` | `run_serial_size_sweep.sh`; optimized and unoptimized serial codes | `results/serial_size_sweep/` |
| GPU work mapping / thread limits (2A/2B) | `qsub vanda_jobs_openmp_gpu_sweep.pbs` | `run_gpu_offload_sweep.sh` | `results/gpu_2a2b_n8192/` |
| GPU team-count sweep (2B) | `qsub vanda_jobs_gpu_2b_teams_n8192.pbs` | `run_gpu_team_sweep.sh` | `results/gpu_2b_teams_n8192/` |
| GPU data movement (2C) | `qsub vanda_jobs_openmp_gpu_mapping.pbs` | `run_gpu_mapping_sweep.sh` | `results/gpu_2c_n8192/` |
| GPU grid-size/team sweep (2D) | `qsub vanda_jobs_openmp_gpu_team_sweep.pbs` | `run_gpu_team_sweep.sh` | `results/openmp_gpu_size_team_sweep/` |
| Hybrid MPI + OpenMP | `qsub vanda_jobs_hybrid_openmp.pbs` | `run_hybrid_openmp_sweep.sh` | `results/hybrid_openmp/` |

PBS output files are created by the scheduler in the project directory. Check job state with `qstat`; after completion, download the relevant result folder from your local machine, for example:

```bash
scp -r cornelius-axel.tjandra@vanda.nus.edu.sg:~/DSA5208-Projects/Project3/results/strong_scaling ./results/
```

**Note:** PBS scripts clear or refresh their experiment-specific result and/or binary folders before running. Download or rename results you want to preserve before resubmitting the same experiment.

## Aggregate scaling runs

Run locally from the project root after downloading the raw per-run CSVs:

```bash
python3 aggregate_strong_scaling.py
python3 aggregate_weak_scaling.py
```

These read `results/{strong,weak}_scaling/all_*_scaling_results.csv` and write the corresponding `all_*_scaling_aggregated.csv`. `aggregate_results.py` aggregates the CPU decomposition/communication sweep; it accepts input and output paths, e.g.:

```bash
python3 aggregate_results.py results/cpu_sweep_intermediate_ranks/all_results.csv results/cpu_sweep_intermediate_ranks/all_results_aggregated.csv
```

## Repository layout

- `heat_*.cpp` — solver implementations: serial optimized/unoptimized, MPI decomposition/communication variants, hybrid MPI/OpenMP, and OpenMP GPU-offload variants.
- `run_*.sh`, `sweep_experiments.sh` — compile, run, log, and record experiment repetitions.
- `vanda_*.pbs` — Vanda PBS resource requests and experiment launch scripts.
- `aggregate_*.py` — local CSV aggregation utilities.
- `results/` — downloaded/generated CSVs, summaries, logs, validation artifacts, and toolchain records, organized by experiment. This data is generally kept out of version control.
- `bin/` — experiment binaries generated by the run scripts.
