================================================================================
           Project 3: macOS Local Testing & Benchmarking Guide
================================================================================
This guide contains all compilation, single-run, and automated benchmark commands
for running Project 3 locally on macOS (Apple Silicon / Intel).

--------------------------------------------------------------------------------
0. Setup & Prerequisites (One-time)
--------------------------------------------------------------------------------
If you want to run OpenMP on macOS with Clang:
  brew install libomp open-mpi

Verify installed tools:
  clang++ --version
  mpicxx --version
  mpirun --version

All executables can be built directly in the project root or placed into `bin/`.
Ensure the helper folders exist:
  mkdir -p bin results/logs

================================================================================
1. The 5 Main Configurations (Implicit Solver with Backward Euler + Jacobi)
================================================================================
All implicit implementations take the same optional command-line arguments:
  ./<executable> [N] [STEPS] [LAMBDA] [MAX_JACOBI_ITERS] [TOL]
  - Default: N=3000, STEPS=1000, LAMBDA=0.05, MAX_JACOBI_ITERS=25, TOL=1e-5
  - Quick test parameters: N=500 STEPS=100 (runs in < 1 second)
  - Medium test parameters: N=1000 STEPS=200 (runs in ~1-2 seconds)

--------------------------------------------------------------------------------

  clang++ -O3 -std=c++17 heat_serial_implicit.cpp -o bin/heat_serial_implicit

Run (default N=3000, STEPS=1000):

================================================================================
2. Investigating Serial vs MPI 1-Core Performance (Locally)
================================================================================
To investigate whether serial runs slower than MPI on a single core, you can run
them side-by-side using the same test parameters:

Step 1: Compile both binaries with the same compiler & flags:
  mpicxx -O3 -std=c++17 heat_serial_implicit.cpp -o bin/heat_serial_implicit
  mpicxx -O3 -std=c++17 heat_mpi_implicit.cpp -o bin/heat_mpi_implicit

Step 2: Run serial (1 core):
  ./bin/heat_serial_implicit 1000 200

Step 3: Run MPI with 1 process (1 core):
  mpirun -np 1 ./bin/heat_mpi_implicit 1000 200

Observations on Mac vs Atlas HPC:
- On macOS (Unified Memory / Apple Silicon):
  Serial runs slightly FASTER than MPI p=1 (e.g. ~0.63s vs ~0.80s) because there
  is no MPI initialization, communicator setup, or halo branches.
- On Atlas HPC (AMD EPYC multi-chiplet architecture):
  If serial is not pinned to a specific core, the Linux kernel scheduler migrates
  the thread across CCXs/NUMA dies, causing huge cache misses (~136s). Meanwhile,
  OpenMPI pinned its process to 1 core (~81s). Using `mpirun -np 1 --bind-to core`
  for the serial code levels the playing field.


================================================================================
3. Automated Benchmarking Scripts (`run_benchmark.sh`)
================================================================================
`run_benchmark.sh` automatically compiles, executes K repetitions, computes
statistics (Mean, Min, Max, StdDev, Speedup, Efficiency), and records to CSV:

Syntax:
  ./run_benchmark.sh <source.cpp> <mpi_procs> <omp_threads> [runs=5] [N] [STEPS]

Examples:
  # 1. Benchmark serial implicit (5 runs, default size):
  ./run_benchmark.sh heat_serial_implicit.cpp 1 1 5

  # 2. Benchmark MPI 1D implicit with 1 process (to compare with serial):
  ./run_benchmark.sh heat_mpi_implicit.cpp 1 1 5

  # 3. Benchmark MPI 1D implicit with 4 processes:
  ./run_benchmark.sh heat_mpi_implicit.cpp 4 1 5

  # 4. Fast benchmark with smaller problem size (N=1000, STEPS=200):
  ./run_benchmark.sh heat_serial_implicit.cpp 1 1 3 1000 200
  ./run_benchmark.sh heat_mpi_implicit.cpp 1 1 3 1000 200
  ./run_benchmark.sh heat_mpi_implicit.cpp 4 1 3 1000 200

Where results go:
  - Text summary: ./results/<experiment_id>_summary.txt
  - Master CSV  : ./results/all_results.csv
  - Raw run logs: ./results/logs/*.log


================================================================================
4. Automated Full Sweep (`sweep_experiments.sh`)
================================================================================
Runs all configurations across specified process counts.

To run a fast test locally (N=1000, STEPS=100, 3 runs each, 1 and 4 cores):
  PROCS_LIST="1 4" ./sweep_experiments.sh 1000 100 3

To run including contiguous 2D block bonus cases:
  RUN_CONTIGUOUS=true PROCS_LIST="1 4" ./sweep_experiments.sh 1000 100 3
