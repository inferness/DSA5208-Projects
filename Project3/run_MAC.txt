========================================
Compilation and Execution Commands
========================================

1. Serial Version - Explicit (heat_serial.cpp)
----------------------------------------
Compile:
  g++ -O3 heat_serial.cpp -o heat_serial
  (or: clang++ -O3 heat_serial.cpp -o heat_serial)

Run:
  ./heat_serial


1b. Serial Version - Implicit (heat_serial_implicit.cpp)
----------------------------------------
Compile:
  g++ -O3 heat_serial_implicit.cpp -o heat_serial_implicit
  (or: clang++ -O3 heat_serial_implicit.cpp -o heat_serial_implicit)

Run (default: N=3000, STEPS=1000):
  ./heat_serial_implicit

Custom parameters: ./heat_serial_implicit [N] [STEPS] [LAMBDA] [MAX_JACOBI_ITERS] [TOL]
  Example (N=500, STEPS=100):
  ./heat_serial_implicit 500 100




2. MPI Version 1 - Blocking Sendrecv (heat_mpi.cpp)
----------------------------------------
Compile:
  mpicxx -O3 heat_mpi.cpp -o heat_mpi

Run (replace 4 with your desired number of MPI processes):
  mpirun -np 4 ./heat_mpi


3. MPI Version 2 - Non-blocking with Overlap (heat_mpi_v2.cpp)
----------------------------------------
Compile:
  mpicxx -O3 heat_mpi_v2.cpp -o heat_mpi_v2

Run (replace 4 with your desired number of MPI processes):
  mpirun -np 4 ./heat_mpi_v2


4. MPI Tiled Version - Cache Tiling (heat_mpi_tile.cpp)
----------------------------------------
Compile:
  mpicxx -O3 heat_mpi_tile.cpp -o heat_mpi_tile

Run (replace 4 with your desired number of MPI processes):
  mpirun -np 4 ./heat_mpi_tile


5. MPI 2D Block Decomposition (heat_mpi_block.cpp)
----------------------------------------
Compile:
  mpicxx -O3 heat_mpi_block.cpp -o heat_mpi_block

Run (replace 4 with your desired number of MPI processes):
  mpirun -np 4 ./heat_mpi_block


6. Hybrid MPI + OpenMP (heat_mpi_openMP.cpp)
----------------------------------------
Compile (using Homebrew libomp for Apple Clang):
  mpicxx -O3 -Xpreprocessor -fopenmp -I/opt/homebrew/opt/libomp/include -L/opt/homebrew/opt/libomp/lib -lomp heat_mpi_openMP.cpp -o heat_mpi_openMP

Run (example: 2 MPI processes, each running 4 OpenMP threads = 8 cores total):
  OMP_NUM_THREADS=4 mpirun -np 2 ./heat_mpi_openMP


7. MPI Version - Implicit Jacobi 1D Row (heat_mpi_implicit.cpp)
----------------------------------------
Compile:
  mpicxx -O3 heat_mpi_implicit.cpp -o heat_mpi_implicit

Run (replace 4 with your desired number of MPI processes):
  mpirun -np 4 ./heat_mpi_implicit

Custom parameters: mpirun -np <p> ./heat_mpi_implicit [N] [STEPS] [LAMBDA] [MAX_JACOBI_ITERS] [TOL]
  Example (N=500, STEPS=100):
  mpirun -np 4 ./heat_mpi_implicit 500 100


8. MPI Version - Implicit Jacobi 2D Block (heat_mpi_block_implicit.cpp)
----------------------------------------
Compile:
  mpicxx -O3 heat_mpi_block_implicit.cpp -o heat_mpi_block_implicit

Run (replace 4 with your desired number of MPI processes):
  mpirun -np 4 ./heat_mpi_block_implicit

Custom parameters: mpirun -np <p> ./heat_mpi_block_implicit [N] [STEPS] [LAMBDA] [MAX_JACOBI_ITERS] [TOL]
  Example (N=500, STEPS=100):
  mpirun -np 4 ./heat_mpi_block_implicit 500 100


9. Hybrid MPI + OpenMP - Implicit Jacobi (heat_mpi_openMP_implicit.cpp)
----------------------------------------
Compile (using Homebrew libomp for Apple Clang):
  mpicxx -O3 -Xpreprocessor -fopenmp -I/opt/homebrew/opt/libomp/include -L/opt/homebrew/opt/libomp/lib -lomp heat_mpi_openMP_implicit.cpp -o heat_mpi_openMP_implicit

Run (example: 2 MPI processes, each running 2 OpenMP threads = 4 cores total):
  OMP_NUM_THREADS=2 mpirun -np 2 ./heat_mpi_openMP_implicit

Custom parameters: OMP_NUM_THREADS=<t> mpirun -np <p> ./heat_mpi_openMP_implicit [N] [STEPS] [LAMBDA] [MAX_JACOBI_ITERS] [TOL]


========================================
Quick One-Liners (Compile & Run)
========================================

# Serial Explicit:
g++ -O3 heat_serial.cpp -o heat_serial && ./heat_serial

# Serial Implicit:
g++ -O3 heat_serial_implicit.cpp -o heat_serial_implicit && ./heat_serial_implicit

# MPI v1 (1D Row):
mpicxx -O3 heat_mpi.cpp -o heat_mpi && mpirun -np 4 ./heat_mpi

# MPI v2 (Non-blocking):
mpicxx -O3 heat_mpi_v2.cpp -o heat_mpi_v2 && mpirun -np 4 ./heat_mpi_v2

# MPI Tiled:
mpicxx -O3 heat_mpi_tile.cpp -o heat_mpi_tile && mpirun -np 4 ./heat_mpi_tile

# MPI 2D Block:
mpicxx -O3 heat_mpi_block.cpp -o heat_mpi_block && mpirun -np 4 ./heat_mpi_block

# Hybrid MPI + OpenMP (Explicit):
mpicxx -O3 -Xpreprocessor -fopenmp -I/opt/homebrew/opt/libomp/include -L/opt/homebrew/opt/libomp/lib -lomp heat_mpi_openMP.cpp -o heat_mpi_openMP && OMP_NUM_THREADS=4 mpirun -np 1 ./heat_mpi_openMP

# MPI Implicit (1D Row):
mpicxx -O3 heat_mpi_implicit.cpp -o heat_mpi_implicit && mpirun -np 4 ./heat_mpi_implicit

# MPI Implicit (2D Block):
mpicxx -O3 heat_mpi_block_implicit.cpp -o heat_mpi_block_implicit && mpirun -np 4 ./heat_mpi_block_implicit

# Hybrid MPI + OpenMP (Implicit):
mpicxx -O3 -Xpreprocessor -fopenmp -I/opt/homebrew/opt/libomp/include -L/opt/homebrew/opt/libomp/lib -lomp heat_mpi_openMP_implicit.cpp -o heat_mpi_openMP_implicit && OMP_NUM_THREADS=2 mpirun -np 2 ./heat_mpi_openMP_implicit


================================================================================
N-Body Simulation Commands
================================================================================

1. Serial Version (NBody_serial.cpp)
----------------------------------------
Compile:
  g++ -O3 NBody_serial.cpp -o NBody_serial
  (or: clang++ -O3 NBody_serial.cpp -o NBody_serial)

Run (default: N=5000 bodies, STEPS=100):
  ./NBody_serial

Custom parameters: ./NBody_serial [N] [STEPS]
  Example (2000 bodies, 50 steps):
  ./NBody_serial 2000 50


1b. Serial Cache-Blocked / Tiled Version (NBody_serial_block.cpp)
----------------------------------------
Compile:
  g++ -O3 NBody_serial_block.cpp -o NBody_serial_block
  (or: clang++ -O3 NBody_serial_block.cpp -o NBody_serial_block)

Run (default: N=5000 bodies, STEPS=100, BLOCK_SIZE=256):
  ./NBody_serial_block

Custom parameters: ./NBody_serial_block [N] [STEPS] [BLOCK_SIZE]
  Example (5000 bodies, 100 steps, block size 256):
  ./NBody_serial_block 5000 100 256


2. MPI Version (NBody_mpi.cpp)
----------------------------------------
Compile:
  mpicxx -O3 NBody_mpi.cpp -o NBody_mpi

Run (default: N=5000 bodies, STEPS=100, replace 4 with number of processes):
  mpirun -np 4 ./NBody_mpi

Custom parameters: mpirun -np 4 ./NBody_mpi [N] [STEPS]
  Example (2000 bodies, 50 steps):
  mpirun -np 4 ./NBody_mpi 2000 50


3. OpenMP Version (NBody_openMP.cpp)
----------------------------------------
Compile (using Homebrew libomp for Apple Clang):
  clang++ -O3 -Xpreprocessor -fopenmp -I/opt/homebrew/opt/libomp/include -L/opt/homebrew/opt/libomp/lib -lomp NBody_openMP.cpp -o NBody_openMP

Run (uses all available CPU threads by default):
  ./NBody_openMP

Custom parameters: ./NBody_openMP [N] [STEPS] [NUM_THREADS]
  Example (5000 bodies, 100 steps, 4 threads):
  ./NBody_openMP 5000 100 4
  (or via env):
  OMP_NUM_THREADS=4 ./NBody_openMP


4. Hybrid MPI + OpenMP Version (NBody_mpi_openMP.cpp)
----------------------------------------
Compile:
  mpicxx -O3 -Xpreprocessor -fopenmp -I/opt/homebrew/opt/libomp/include -L/opt/homebrew/opt/libomp/lib -lomp NBody_mpi_openMP.cpp -o NBody_mpi_openMP

Run (example: 2 MPI processes, each with 4 OpenMP threads = 8 workers total):
  OMP_NUM_THREADS=4 mpirun -np 2 ./NBody_mpi_openMP
