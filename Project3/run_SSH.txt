--------------------------------------------------------------------------------
4. Common PBS Cluster Job Management Commands (Run inside Atlas SSH)
--------------------------------------------------------------------------------
Navigate to project directory:
  cd ~/DSA5208-Projects/Project3

Pull latest code:
  git pull

Submit batch job:
  qsub -q parallel atlas_job.pbs

Submit with custom core list (e.g. 1 4 16 32):
  qsub -q parallel -v PROCS_LIST="1 4 16 32" atlas_job.pbs

Check status of your running/queued jobs:
  qstat -u cornelius-axel.tjandra

Check wide status format (shows queue, elapsed time, state):
  qstat -w -u cornelius-axel.tjandra

Check why a queued job hasn't started yet:
  qstat -f <JobID> | grep -i comment

View full details of a specific job:
  qstat -f <JobID>

Cancel / delete a job:
  qdel <JobID>

Monitor real-time progress while job runs:
  ls -lt results/logs/
  tail -f results/pbs_job.log
