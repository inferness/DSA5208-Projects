================================================================================
Compilation and Execution Commands (Windows - MSYS2 UCRT64 + MS-MPI)
================================================================================

[Setup / PATH Note]
Before running the commands below in PowerShell, make sure g++, mpicxx, and
mpiexec are available in your PATH by running this once in your terminal session:

  PowerShell:
    $env:PATH = "C:\msys64\ucrt64\bin;C:\Program Files\Microsoft MPI\Bin;" + $env:PATH

  Command Prompt (cmd.exe):
    set PATH=C:\msys64\ucrt64\bin;C:\Program Files\Microsoft MPI\Bin;%PATH%

(Tip: In MSYS2 UCRT64 shell or if already added to System PATH, no setup is needed)


1. Serial Version - Explicit (heat_serial.cpp)
----------------------------------------
Compile:
  g++ -O3 heat_serial.cpp -o heat_serial.exe

Run:
  PowerShell:   .\heat_serial.exe
  CMD / Bash:   heat_serial.exe


1b. Serial Version - Implicit (heat_serial_implicit.cpp)
----------------------------------------
Compile:
  g++ -O3 heat_serial_implicit.cpp -o heat_serial_implicit.exe

Run (default: N=3000, STEPS=1000):
  PowerShell:   .\heat_serial_implicit.exe
  CMD / Bash:   heat_serial_implicit.exe

Custom parameters: ./heat_serial_implicit.exe [N] [STEPS] [LAMBDA] [MAX_JACOBI_ITERS] [TOL]
  Example (N=500, STEPS=100):
  PowerShell:   .\heat_serial_implicit.exe 500 100



2. MPI Version 1 - Blocking Sendrecv (heat_mpi.cpp)
----------------------------------------
Compile:
  mpicxx -O3 heat_mpi.cpp -o heat_mpi.exe

Run (replace 4 with your desired number of MPI processes):
  PowerShell:   mpiexec -n 4 .\heat_mpi.exe
  CMD / Bash:   mpiexec -n 4 heat_mpi.exe


3. MPI Version 2 - Non-blocking with Overlap (heat_mpi_v2.cpp)
----------------------------------------
Compile:

Run (replace 4 with your desired number of MPI processes):
  PowerShell:   mpiexec -n 4 .\heat_mpi_v2.exe
  CMD / Bash:   mpiexec -n 4 heat_mpi_v2.exe

  CMD / Bash:   mpiexec -n 4 heat_mpi_block.exe


6. Hybrid MPI + OpenMP (heat_mpi_openMP.cpp)
----------------------------------------
Compile:
  mpicxx -O3 -fopenmp heat_mpi_openMP.cpp -o heat_mpi_openMP.exe

Run (example: 2 MPI processes, each running 4 OpenMP threads = 8 cores total):
  PowerShell:
    $env:OMP_NUM_THREADS = 4; mpiexec -n 2 .\heat_mpi_openMP.exe
    (or using MS-MPI -env flag):
    mpiexec -env OMP_NUM_THREADS 4 -n 2 .\heat_mpi_openMP.exe

  CMD:
    set OMP_NUM_THREADS=4 && mpiexec -n 2 heat_mpi_openMP.exe

================================================================================
N-Body Simulation Commands
================================================================================

1. Serial Version (NBody_serial.cpp)
----------------------------------------
Compile:
  g++ -O3 NBody_serial.cpp -o NBody_serial.exe

Run (default: N=5000 bodies, STEPS=100):
  PowerShell:   .\NBody_serial.exe
  CMD / Bash:   NBody_serial.exe

Custom parameters: ./NBody_serial.exe [N] [STEPS]
  Example (2000 bodies, 50 steps):
  .\NBody_serial.exe 2000 50


1b. Serial Cache-Blocked / Tiled Version (NBody_serial_block.cpp)
----------------------------------------
Compile:
  g++ -O3 NBody_serial_block.cpp -o NBody_serial_block.exe

Run (default: N=5000 bodies, STEPS=100, BLOCK_SIZE=256):
  PowerShell:   .\NBody_serial_block.exe
  CMD / Bash:   NBody_serial_block.exe

Custom parameters: ./NBody_serial_block.exe [N] [STEPS] [BLOCK_SIZE]
  Example (5000 bodies, 100 steps, block size 256):
  .\NBody_serial_block.exe 5000 100 256


2. MPI Version (NBody_mpi.cpp)
----------------------------------------
Compile:
  mpicxx -O3 NBody_mpi.cpp -o NBody_mpi.exe

Run (default: N=5000 bodies, STEPS=100, replace 4 with number of processes):
  PowerShell:   mpiexec -n 4 .\NBody_mpi.exe
  CMD / Bash:   mpiexec -n 4 NBody_mpi.exe

Custom parameters: mpiexec -n 4 .\NBody_mpi.exe [N] [STEPS]
  Example (2000 bodies, 50 steps):
  mpiexec -n 4 .\NBody_mpi.exe 2000 50


3. OpenMP Version (NBody_openMP.cpp)
----------------------------------------
Compile:
  g++ -O3 -fopenmp NBody_openMP.cpp -o NBody_openMP.exe

Run (uses all available CPU threads by default):
  PowerShell:   .\NBody_openMP.exe
  CMD / Bash:   NBody_openMP.exe

Custom parameters: .\NBody_openMP.exe [N] [STEPS] [NUM_THREADS]
  Example (5000 bodies, 100 steps, 4 threads):
  PowerShell:   .\NBody_openMP.exe 5000 100 4
  (or via env): $env:OMP_NUM_THREADS = 4; .\NBody_openMP.exe


4. Hybrid MPI + OpenMP Version (NBody_mpi_openMP.cpp)
----------------------------------------
Compile:
  mpicxx -O3 -fopenmp NBody_mpi_openMP.cpp -o NBody_mpi_openMP.exe

Run (example: 2 MPI processes, each with 4 OpenMP threads = 8 workers total):
  PowerShell:
    mpiexec -env OMP_NUM_THREADS 4 -n 2 .\NBody_mpi_openMP.exe
    (or set env var):
    $env:OMP_NUM_THREADS = 4; mpiexec -n 2 .\NBody_mpi_openMP.exe

  CMD / Bash:
    set OMP_NUM_THREADS=4 && mpiexec -n 2 NBody_mpi_openMP.exe
